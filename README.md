# 🐾 Sobre o Projeto

O **PetCare Hub** é uma plataforma integrada de monitoramento preventivo veterinário.

A solução busca transformar a jornada de saúde do pet de um modelo episódico e reativo para um modelo contínuo, preventivo e orientado por dados.

<br>

A plataforma conecta:

- 📱 aplicações mobile;
- ☕ APIs backend;
- 📡 sensores IoT;
- 🗄️ banco de dados Oracle;
- ☁️ infraestrutura em nuvem.

<br>

O objetivo é aumentar:

- continuidade do cuidado;
- engajamento do responsável;
- retenção de clientes;
- recorrência clínica;
- geração de dados estruturados;
- previsibilidade operacional para clínicas veterinárias.

<br>

# 💡 Contexto do Projeto

O PetCare Hub propõe um ecossistema digital integrado para monitoramento preventivo veterinário.

A solução utiliza sensores IoT, aplicações móveis, APIs REST e análise de dados para gerar alertas preventivos, acompanhar padrões comportamentais do pet e fornecer suporte à tomada de decisão clínica.

<br>

## 🎯 Objetivos

- Transformar o cuidado veterinário de reativo para preventivo;
- Consolidar dados clínicos e comportamentais em um histórico longitudinal;
- Melhorar o engajamento e retenção dos responsáveis;
- Aumentar a recorrência clínica;
- Gerar inteligência baseada em dados e comportamento.

<br>

## ⚙️ Funcionalidades

### 🐕 Coleira Smart

Dispositivo IoT responsável pelo monitoramento comportamental do pet.

#### Funcionalidades

- monitoramento de movimentação;
- análise de padrão de atividade;
- identificação de comportamento anômalo;
- detecção de períodos prolongados de inatividade.

<br>

### 🍽️ Comedouro Inteligente

#### Funcionalidades

- monitoramento alimentar;
- controle automatizado de porções;
- histórico de consumo;
- acompanhamento de rotina alimentar.

<br>

### 🌡️ Monitor de Ambiente

#### Funcionalidades

- monitoramento de temperatura ambiente;
- controle de umidade;
- acompanhamento da qualidade do ar.

<br>

### 📊 Score de Saúde

Indicador visual calculado com base em:

- atividade física;
- comportamento do pet;
- alimentação;
- qualidade do ambiente;
- histórico preventivo;
- recorrência clínica.

<br>

### 🚨 Alertas Preventivos

A plataforma gera alertas inteligentes relacionados a:

- alteração de comportamento;
- baixa atividade;
- rotina alimentar irregular;
- vacinas pendentes;
- consultas preventivas atrasadas.
